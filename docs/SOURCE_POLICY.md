# Source Policy

The application must only use lawful and appropriate sources.

Allowed future categories include:

- Official university pages.
- Official faculty homepages.
- OpenAlex.
- Crossref.
- arXiv.
- ORCID public APIs.
- Institutional repositories.
- Publisher open-access files.

Disallowed:

- Google Scholar scraping.
- Paywall bypass.
- Shadow libraries.
- CAPTCHA bypass.
- Proxy rotation to evade restrictions.
- Guessed email addresses.
- Commercial email enrichment.

No crawling or external source integration is implemented in Phase 0.
